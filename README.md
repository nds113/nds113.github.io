# Nikolaus Salvatore personal academic website

A static, single-page academic website prepared for GitHub Pages. The visual structure follows the compact, understated style of the reference site while using original HTML and CSS.

## Deploy

1. Create a public GitHub repository named `nds113.github.io`.
2. Upload the contents of this folder to the repository root.
3. Open **Settings > Pages**.
4. Choose **Deploy from a branch**, select `main`, and choose `/(root)`.
5. The site will publish at `https://nds113.github.io`.

## Before publishing

- Replace `images/profile-placeholder.svg` with a professional portrait. Keep the filename or update the image path in `index.html`.
- Add a target postdoc start date to the postdoc notice when known.
- Replace `docs/Nikolaus_Salvatore_CV.pdf` whenever the CV changes.
- Add the exact titles of the 2023 and 2026 CEMS presentations.
- Add Google Scholar and LinkedIn links when available.
- Add semesters and specific TA responsibilities if desired.
